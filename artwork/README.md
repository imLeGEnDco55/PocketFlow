# PocketFlow branding

Approved neon PF icon and transparent logo, with Android density variants in app/src/main/res.

The adaptive foreground uses an 86dp inset inside the 108dp layer; the central PF stays within the launcher safe area. The splash uses 192dp artwork centered in a transparent 288dp canvas. Decorative waves may be masked by the launcher.

The application ID, signing configuration, and legacy PocketTracker data folder are preserved for update compatibility.
